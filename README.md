# Kai Wu

Computational Astrophysicist  
Postdoctoral researcher at Astronomisches Rechen-Institut, Zentrum fuer Astronomie, Heidelberg University.

I study star clusters, planetary systems, and free-floating planets with direct N-body simulations.

Current work includes the DRAGON simulation series, planetary systems in star clusters, and NBODY6++GPU development.
